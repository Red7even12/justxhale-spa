I. Core Server Architecture
Hosting: A single "Linux Epyc VPS 3" from Domains.co.za.
Operating System: Ubuntu 22.04 LTS, hardened with a non-root gtw_admin user and UFW firewall.
Containerization: The entire server operates on a container-based model using Docker and Docker Compose.
Traffic Management: A single Nginx Proxy Manager container acts as the master reverse proxy. It handles all incoming HTTP (80) and HTTPS (443) traffic, terminates SSL, and forwards requests to the appropriate application container.
Multi-Tenancy Model: Each major project (like "Vizabiliti Estates") is defined in its own docker-compose.yml file within a dedicated directory (e.g., ~/docker/vizabiliti). All application containers that need to be accessed from the web are connected to a shared Docker network named npm_network, making them visible to the Nginx Proxy Manager.
